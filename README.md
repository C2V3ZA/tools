# C2V3ZA Tools

Public static website for `https://github.com/C2V3ZA/tools`.

The public repository contains only the website, tool ZIP downloads, screenshots, and the generated `data/tools.json`.

**Do not put the `LOCAL-ADMIN` folder into this repository.**

GitHub Pages URL:
`https://c2v3za.github.io/tools/`

The UI automatically detects German or English from the browser and provides a manual DE/EN switch.
